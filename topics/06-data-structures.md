# 6. Data Structures

## Core Question

Why are data structures important, and how do they organize information?

## Detailed Explanation

A data structure is a way of storing and organizing data so that it can be used efficiently.

Different problems require different ways of organizing data.

### Common data structures

1. Arrays
   - A collection of elements stored in order.
   - Easy to access by index.

2. Lists
   - Similar to arrays but often dynamic in size.
   - Useful when the number of items changes.

3. Stacks
   - Follows the Last In, First Out (LIFO) rule.
   - Example: browser back button.

4. Queues
   - Follows the First In, First Out (FIFO) rule.
   - Example: waiting line in a store.

5. Linked lists
   - A sequence of nodes where each node points to the next.
   - Useful for dynamic insertion and deletion.

6. Trees
   - A hierarchical structure with parent and child nodes.
   - Example: file systems.

7. Graphs
   - Consist of nodes connected by edges.
   - Used to model networks and relationships.

8. Hash tables
   - Store data using keys for fast lookup.
   - Common in dictionaries and maps.

### Why data structures matter

If data is stored poorly, programs may become slow or difficult to manage.

For example:

- searching a large unsorted list is inefficient
- a hash table allows fast lookup by key
- a queue is useful for processing tasks in order

### Choosing the right structure

The best data structure depends on the problem:

- need fast insertion? use linked list or hash table
- need ordered access? use arrays or lists
- need hierarchical relationships? use trees
- need relationships between entities? use graphs

### In summary

Data structures determine how information is organized and accessed. They are central to efficient algorithm design and software performance.

## Key Takeaways

- Data structures organize information for efficient processing.
- Different structures fit different tasks.
- Good choices improve performance and clarity.

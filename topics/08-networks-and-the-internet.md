# 8. Networks and the Internet

## Core Question

How do computers connect and communicate over networks?

## Detailed Explanation

A network is a group of connected devices that can share information.

The internet is the largest and most important network in the world. It connects computers, servers, and devices across countries and continents.

### Basic concepts

1. IP address
   - An IP address identifies a device on a network.
   - Example: 192.168.1.10

2. Protocols
   - Protocols are rules for communication.
   - Common examples: HTTP, HTTPS, TCP/IP.

3. Routers and switches
   - Routers direct data between networks.
   - Switches connect devices within a local network.

4. Client and server
   - A client requests information.
   - A server provides it.

### How data travels

When you open a website, your browser sends a request to a server. The request travels through routers and networks until it reaches the server. The server sends the page back, and your browser displays it.

### The internet vs the web

- The internet is the underlying network infrastructure.
- The web is a system of websites and web pages that uses the internet.

### Why networks matter

Networks enable:

- email
- browsing
- online learning
- messaging
- cloud computing
- remote work

### Security in networks

Networks must protect data from attacks. Security methods include:

- firewalls
- encryption
- authentication
- secure protocols such as HTTPS

### In summary

Networks allow devices to communicate and share resources. The internet is a huge global network that enables modern digital communication and collaboration.

## Key Takeaways

- Networking is about communication between devices.
- Protocols and addresses make communication possible.
- Security is critical in a connected world.

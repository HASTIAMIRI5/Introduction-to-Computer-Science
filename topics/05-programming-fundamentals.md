# 5. Programming Fundamentals

## Core Question

What are the basic concepts of programming?

## Detailed Explanation

Programming is the process of writing instructions that a computer follows to perform a task.

A programmer uses a programming language to express logic. Common languages include:

- Python
- Java
- C++
- JavaScript
- C#

### Basic programming concepts

1. Variables
   - A variable stores a value.
   - Example: `age = 20`

2. Data types
   - Different values have different types.
   - Examples: integers, floating-point numbers, strings, booleans.

3. Operators
   - Operators perform actions such as addition, subtraction, comparison, and logical checks.

4. Control structures
   - These control the execution path.
   - Examples: if statements, loops, switch statements.

5. Functions
   - Functions are reusable blocks of code.
   - They help reduce repetition and improve organization.

6. Input and output
   - Programs often receive input from a user or file and produce output.

### Example in Python

```python
name = "Alice"
age = 21

if age >= 18:
    print(name + " is an adult.")
else:
    print(name + " is not an adult.")
```

### Why programs need logic

Computers do not think creatively; they follow instructions exactly. A programmer must write logic carefully to avoid bugs and unexpected results.

### Debugging

Debugging is the process of finding and fixing errors in a program.

Common types of errors:

- syntax errors
- runtime errors
- logical errors

### Good programming practices

- write readable code
- use meaningful variable names
- comment code when necessary
- test small parts often
- keep functions simple and focused

### In summary

Programming fundamentals teach us how to express problem-solving steps in a form that computers can execute. It is the practical application of algorithmic thinking.

## Key Takeaways

- Programming is writing instructions for computers.
- Variables, loops, conditions, and functions are core concepts.
- Good code is correct, readable, and testable.

# 3. Computer Organization and Hardware

## Core Question

What are the basic parts of a computer, and how do they work together?

## Detailed Explanation

A computer is made of hardware and software. Hardware includes physical components, while software includes instructions and programs that tell the hardware what to do.

### Main hardware components

1. Central Processing Unit (CPU)
   - The CPU is the brain of the computer.
   - It performs calculations and executes instructions.
   - It contains the control unit and arithmetic logic unit (ALU).

2. Memory
   - Memory stores data and instructions temporarily.
   - RAM (Random Access Memory) is fast and used while programs are running.
   - ROM or storage devices are used for longer-term information.

3. Storage
   - Storage keeps data even when the power is off.
   - Examples include SSDs and hard drives.

4. Input devices
   - These allow users to provide information.
   - Examples: keyboard, mouse, scanner, microphone.

5. Output devices
   - These display or deliver results.
   - Examples: monitor, printer, speaker.

### How a computer works

A user enters data using an input device. The CPU fetches instructions from memory, decodes them, and executes them. Results may be stored in memory or sent to output devices.

This flow is often described as:

Input -> Processing -> Output

### The role of the CPU

The CPU performs operations such as:

- arithmetic
- comparisons
- logic operations
- moving data
- control flow

The CPU follows instructions from the program.

### Memory hierarchy

Different types of memory have different speeds and costs:

- registers (very fast, small)
- cache memory
- RAM
- secondary storage

This arrangement helps the system operate efficiently.

### Motherboard and bus systems

The motherboard connects the main components. Data travels through buses, which are pathways inside the computer. These allow communication between the CPU, memory, storage, and peripherals.

### Types of computers

- personal computers
- servers
- laptops
- embedded systems
- supercomputers

Each type is designed for a different workload.

### In summary

Computer organization explains how the physical parts of a system are arranged and interact. It is the foundation of understanding how software runs on hardware.

## Key Takeaways

- Hardware is the physical side of computing.
- The CPU, memory, and storage are critical components.
- Input and output devices connect computers to users and the world.
- Computer organization explains how all parts work together.

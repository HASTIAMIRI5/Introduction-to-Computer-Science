# 9. Software Engineering

## Core Question

How do we design and build reliable software systems?

## Detailed Explanation

Software engineering is the application of engineering principles to software development.

It is not just writing code. It includes:

- planning
- design
- testing
- maintenance
- teamwork
- quality assurance

### The software development lifecycle

A common lifecycle includes:

1. Requirements analysis
   - Understand user needs.

2. Design
   - Decide how the system will work.

3. Implementation
   - Write the code.

4. Testing
   - Check whether the system works correctly.

5. Deployment
   - Release the software to users.

6. Maintenance
   - Fix bugs and improve features over time.

### Why software engineering matters

Large software systems are complex. Without good planning, they can become confusing, unreliable, and difficult to maintain.

### Good engineering practices

- modular design
- clear documentation
- testing
- version control
- code review
- use of design patterns when appropriate

### Teamwork

Many software projects are built by teams. Developers must communicate, document decisions, and coordinate tasks.

### In summary

Software engineering focuses on building software that is correct, maintainable, efficient, and useful over time.

## Key Takeaways

- Software engineering is more than coding.
- It emphasizes quality, testing, design, and maintainability.
- Good systems require planning and teamwork.
